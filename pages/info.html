Hello!

As the name says, fishexperiments is an experimental imageboard with a single global board. There is no account system, and all posts are anonymous by default.

Imageboards are internet forums where people start threads by posting an image and some text, and others reply to them. The big ones move quickly, and old threads are deleted as new ones appear. That's really all you need to know.

Read the rules, use the top bar to navigate the website further, and finally use the button below to continue.
